    Getting Started

    1. Choose your mode. MCP Server (for Claude Desktop) or Browser-Based Agents (DeepSeek, Gemini, ChatGPT, or any other browser AI chat). Pick based on which AI you actually use — you can switch anytime from the sidebar.
    2. Load your file(s). Click "Select File(s)" and pick a CSV or Excel file. Nothing uploads anywhere — the file stays on your computer the whole time.
    3. Copy the system prompt. One click copies it. Paste it as your first message to the AI — this is what teaches it how to talk to your data.
    4. (Browser-Based Agents mode only) Ask your question in the chat as normal. bigsip watches your clipboard automatically — when the AI asks for your data, the answer gets copied back for you to paste. No extra steps.
    5. (MCP Server mode only) Set up the connection once (button on this screen), restart Claude Desktop, then just ask it about your data directly — no copy-pasting needed, ever again.

    What Is What

    • System Prompt — instructions that teach the AI how to ask bigsip for data. Always copy this first, before asking your real question.
    • MCP Server — direct connection method for Claude Desktop. Set up once; after that, Claude Desktop talks to bigsip automatically.
    • Clipboard Bridge — connection method for browser AI chats. It watches your clipboard and relays queries and answers.
    • Loaded Tables — inspect columns and sample rows directly inside the Load Your Data section.
    • Query Tester — run custom SQL queries against your data locally inside bigsip.
    • Reset Session — clears everything and starts fresh.
    • Status — monitors memory usage and connection health.
